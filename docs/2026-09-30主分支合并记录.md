## 构建与测试修复

1. 上游 `cc 1.2.48` 与 `find-msvc-tools 0.1.13` 在 Windows 上存在 `FILE_ATTRIBUTE_TEMPORARY` 类型不兼容。仅将锁文件中的 `find-msvc-tools` 固定为 `0.1.5`，不修改 Cargo 缓存源码。
2. 新后台启动流程超过 Windows 默认 1 MiB 主线程栈。先用临时 PE 副本验证 8 MiB 后端到端通过，再在 pager-bin 的 Windows/MSVC 链接参数中正式设置 `/STACK:8388608`；正式产物已确认栈预留值。
3. Transform 链式测试将 PowerShell 内联局部变量误当环境变量预检；测试脚本改写临时文件执行，生产规则不变。
4. 上游资产路径测试的 Unix 符号链接调用改为平台对应 API，测试未跳过。
5. 外部认证目录测试按新上游规则提供预取目录，不再假设外部模式加载本地模型条目；失效断言完整保留。
